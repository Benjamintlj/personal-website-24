# Software Engineering SOFT20111

Leader: Neil Sculthorpe

Lab tutors: David Adama, Salisu Yahaya

# What you will Learn

- Demonstrate understanding of test-design principles
- Demonstrate awareness of code-quality issues

- Use a variety of software tools and technologies for software development
- Design and implement robust software components
- Contribute to team-based software-development projects
- Interact effectively with version-control systems and continuous-integration servers
- Demonstrate proficiency with modern software-development practices
- Choose appropriate structures and library components
