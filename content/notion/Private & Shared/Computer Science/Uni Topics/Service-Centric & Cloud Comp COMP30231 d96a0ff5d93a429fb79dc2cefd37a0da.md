## Week by week

Week 1: Fundamentals of service centric distributed object computing

Week 2: Client-server architectures & Revisiting sockets, TCP, HTTP

Week 3: Calling code on other machines & Remote Procedure Calls / Remote Method Invocation

Week 4 & 5: Calling remote services & Service Oriented Architectures, data exchange formats, REST, Web Services

Week 6: Message queues & publish-subscribe, AMQP

Week 7 & 8: Cloud Computing & MS Azure Fundamentals (AZ-900T0x): Modules 01, 02, 03 → MS Azure Fundamentals Certification (AZ-900)

Week 9: Containers and microservices & MS Azure Fundamentals (AZ-900T0x): Module 02 → MS Azure Fundamentals Certification (AZ-900)

Week 10: Coursework revision

Week 11 & 12: Big Data & Overview, use cases on the cloud
