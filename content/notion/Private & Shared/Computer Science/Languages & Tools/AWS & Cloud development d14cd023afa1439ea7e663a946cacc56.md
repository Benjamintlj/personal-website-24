# AWS & Cloud development

## Pre-requisites

This tutorial series assumes you have a basic understanding of the following:

- Basic knowledge of computer science concepts, if you have done CS at uni or probably even A-level I am sure you will be fine! 😁
- What is networking and how it works at a basic level. If you don’t know anything or thinK that you need to know more have a look at this other tutorial I made (It’s probs a 3 hour read, trust me its worth it)

[Networking](../Networking%209ec1bf738b104e5d83200f5cdd3af025.md)

## A personal note

- If you are just starting out, there is a tendency for tutorials to lob pricing rubbish at you. Unless you are going commercial it really does not matter, and it just more junk getting shoved into your brain. There is only so much time in the day so don’t waste it on marketing.
- My recommendation is to get practical ASAP. Sadly, with cloud this is a-bit harder than with other subjects, as you need to get familiar with the basic concepts and how to navigate the AWS website. **AWS cloud quest** ( cloud practitioner, and solutions architect ) courses are a pretty good practical way to do it especially the cloud practitioner course to understand the very basics. Just skip the pricing rubbish.

[AWS Cloud Quest | Interactive Role-Playing Game | AWS](https://aws.amazon.com/training/digital/aws-cloud-quest/)
