# Benchmarking

[testing package - testing - Go Packages](https://pkg.go.dev/testing#hdr-Benchmarks)

# CLI

```bash
go test -bench=.            # execute benchmarks
go test -bench=. -benchmem  # show memory allocations
```

## Example Code

```bash
func BenchmarkRepeat(b *testing.B) {
	for i := 0; i < b.N; i++ {
		Repeat("a")
	}
}
```
